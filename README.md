# 💻 DevFolio App — Carteira & Portfólio do Desenvolvedor Mobile

## 📌 Sobre o projeto

O **DevFolio App** é um aplicativo desenvolvido em Flutter como parte de uma atividade acadêmica, com o objetivo de criar uma carteira digital para desenvolvedores mobile.

A proposta é reunir informações importantes do desenvolvedor em um único lugar, apresentando seu perfil, habilidades, ferramentas utilizadas e estatísticas em uma interface moderna e organizada.

O projeto foi desenvolvido em dupla, buscando aplicar na prática os conhecimentos de desenvolvimento mobile, organização de código e construção de interfaces com Flutter.

## 🎯 Objetivo

Desenvolver um aplicativo que funcione como um portfólio digital, permitindo apresentar informações profissionais e técnicas de maneira visual, simples e intuitiva.

## ✨ Funcionalidades

- **Perfil do desenvolvedor:** apresentação de informações pessoais e profissionais.
- **Crachá digital:** identificação visual do desenvolvedor.
- **Habilidades:** exibição das principais tecnologias e conhecimentos.
- **Dashboard:** painel com estatísticas e informações relevantes.
- **Ferramentas:** apresentação de ferramentas utilizadas no desenvolvimento.
- **Interface personalizada:** layout moderno, organizado e responsivo.

## 🛠️ Tecnologias utilizadas

- Flutter
- Dart
- Material Design 3
- Visual Studio Code

## 📱 Estrutura do aplicativo

O aplicativo foi organizado em duas áreas principais:

**1. Perfil e Crachá**
- Informações do desenvolvedor.
- Identificação profissional.
- Habilidades e conhecimentos técnicos.

**2. Dashboard**
- Estatísticas do desenvolvedor.
- Cards informativos.
- Organização visual das informações.

## 🚀 Como executar o projeto

1. Clone o repositório:

```bash
git clone 
```

2. Entre na pasta do projeto:

```bash
cd devfolio_app
```

3. Instale as dependências:

```bash
flutter pub get
```

4. Execute o aplicativo:

```bash
flutter run
```
